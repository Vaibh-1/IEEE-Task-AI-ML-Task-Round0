# IEEE-Task-AI-ML-Task-Round0
Requirements
Python 3.8 or higher
Libraries:
numpy
pandas
matplotlib


Project Structure
File	    Description
task1.py	List analyzer — creates a list from user input
task2.py	List functions — sum, max, min, odd/even count (implemented manually, without built-in functions)
task3.py	Checks whether a given number is prime
task4.py	NumPy basics — array creation, data type, shape, and operations
task5.py	CSV data analysis using Pandas
task6.py	Data visualization using Matplotlib (bar chart, histogram)
student_performance.csv	Dataset used by task5.py and task6.py


Each task is a standalone script. Run them individually from the terminal:
python task1.py
python task2.py
python task3.py
python task4.py
python task5.py
python task6.py

Note: task5.py and task6.py require student_performance.csv to be in the same folder as the script.(or define the path to where it is stored in the the input area)
